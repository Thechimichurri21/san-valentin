# San Valentín - Landing interactiva

Landing de propuesta de San Valentín con React, Next.js, Tailwind, Framer Motion y confeti.

## Instalación

```bash
npm install
```

Dependencias principales: `canvas-confetti`, `framer-motion`, `next`, `react`.

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
